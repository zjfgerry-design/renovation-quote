# 装修建材智能报价系统 · Renovation Quote

面向中国装修公司、建材商家的中文网页 MVP。使用 Next.js App Router、React、TypeScript、Tailwind CSS，无登录、数据库、AI API 或收费服务。

## 安装与运行

要求 Node.js 20.9+（当前在 Node.js 24.19.0 / npm 11.9.0 验证）。

```sh
npm ci
npm run dev
```

浏览器打开 http://localhost:3000。生产模式本地验证：

```sh
npm run build
npm start
```

## 功能与使用

- 工作台：材料数、当前报价明细数和总额，提供流程入口。
- 材料管理：12 条虚构建材演示数据，支持搜索、添加、编辑和确认删除。
- 创建报价：填写客户、项目、日期，选择材料、输入数量、修改数量或移除明细。
- 预览：填写必要信息后打印 A4 报价单，浏览器选择“另存为 PDF”；建议关闭页眉页脚。
- 页面适配桌面、平板与手机；窄屏材料表支持横向滚动。

材料单价以整数分保存，数量最多三位小数，使用 BigInt 对乘法结果四舍五入到分；总额累加各单项金额。单价上限 1,000,000 元，数量上限 100,000。材料添加到报价时保存快照，后续修改或删除材料不会影响已有明细。数量编辑在离开输入框时校验并保存；非法输入恢复原值。

## 数据与限制

数据使用当前浏览器当前站点的 localStorage（键 `renovation-quote-v1`）保存。刷新可恢复，但不会跨浏览器、设备或域名同步。清理浏览器数据可能导致丢失。首次访问使用演示材料，未修改前无需写入存储。

保存失败时页面明确提示；读取到损坏数据时不覆盖原值，当前会话仍可操作。只有一份当前报价草稿，尚无多报价归档、备份导入导出、税率折扣、账号或云同步。所有演示数据均为虚构，金额仅用于演示。正式业务使用前请自行核对并及时打印保存。

## 检查与测试

```sh
npm run typecheck
npm test
npm run build
npm run test:e2e
```

单元测试覆盖十进制输入、整数金额与舍入、材料快照及损坏数据。浏览器测试覆盖材料增删改、报价编辑、刷新保存、删除材料后快照、预览、生成 A4 PDF、移动宽度与损坏数据保护。

浏览器测试默认使用 `/usr/bin/chromium`，其他环境通过 `CHROMIUM_PATH=/path/to/chromium npm run test:e2e` 指定 Chromium 路径。配置自动启动本地开发服务器；PDF 验证输出位于 `/tmp/renovation-quote-test.pdf`。浏览器测试需要允许启动子进程和监听本地端口。

## 代码结构

- `src/app/`：工作台、材料管理、报价编辑、打印预览与响应式样式。
- `src/components/`：应用导航与本地数据状态管理。
- `src/lib/model.ts`：数据类型、演示数据、金额计算与存储格式校验。
- `tests/`：业务单元测试与浏览器流程测试。

本项目尚未部署生产环境。
